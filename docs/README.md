# MaintIE Documentation

This directory contains all documentation for the MaintIE project, organized by category.

## Directory Structure

### 📁 `project-info/`
Core project documentation and information:
- `GUIDELINES.md` - Project guidelines and conventions
- `MODELS.md` - Model architecture and implementation details  
- `RESULTS.md` - Experimental results and performance metrics
- `SCHEME.md` - Data schema and annotation guidelines

### 📁 `azure-ml/`
Azure ML deployment and replication documentation:
- `maintie_code_modifications.md` - Required code changes for Azure ML compatibility
- `maintie_replication_guide.md` - Step-by-step replication instructions

### 📁 `images/`
Visual assets and diagrams:
- `annotation_and_experiment_process.png` - Annotation and experiment workflow
- `example_tagged_texts.png` - Example of tagged text samples
- `maintie_entity_hierarchy.png` - Entity relationship hierarchy diagram

## Quick Navigation

- **Getting Started**: See main `README.md` in project root
- **Azure ML Setup**: Start with `azure-ml/maintie_replication_guide.md`
- **Data Format**: Check `project-info/SCHEME.md`
- **Model Details**: Review `project-info/MODELS.md`
- **Results**: View `project-info/RESULTS.md`
